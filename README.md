# Quick Notes

Built with [Typst](https://typst.app).

## Editing

- **`resume.typ`** — all content lives here
- **`template.typ`** — layout engine, touch only for spacing/styling changes

## Commands

```bash
# Live preview (auto-recompiles on save)
typst watch resume.typ johnson-resume.pdf

# One-off compile
typst compile resume.typ johnson-resume.pdf
```
